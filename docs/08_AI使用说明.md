# 08 AI 使用说明

本项目在开发过程中使用了 AI 助手（DeepSeek Harness，模型 deepseek-flash）。这份说明写清用了什么、怎么用的、哪些是自己做的，便于核查。

## 用了什么

- 工具：DeepSeek Harness（桌面端，Web 界面）
- 模型：deepseek-flash
- 会话记录：`.agents/sessions/` 下按日期保存，一次会话一个文件，包含每轮的问题、决定、执行的操作和验证结果

## AI 做了什么

- 解释概念：Maven Wrapper、Spring Boot 启动流程、注解作用、Vue 响应式、事务
- 提供代码草稿：实体、仓库、Service、Controller、前端页面、样式
- 排查错误：端口占用、主键冲突、Vue 插件未加载、编译错误、`@GeneratedValue` 缺失导致的 500
- 设计校验顺序与文档结构（README、自查清单、本说明）

## 自己做了什么

- 安装 JDK 与 Node 环境，执行 Spring Initializr 生成工程，执行 `npm create vite` 生成前端工程
- 每次改代码后自己启动前后端、在浏览器点击、用 curl 验证结果
- 建分支、写 commit、推送、创建 PR、合并 PR
- 数据库重置与种子数据插入（H2 控制台）
- 演示截图（`docs/images/`）

## 怎么记录

- 使用 AI 的提交在正文后附三行：`AI-Assisted-By`、`AI-Contribution`、`Human-Verified`
- `Human-Verified` 只写实际做过的检查；没做的写"待确认"
- 会话日志随项目提交，未使用 AI 的提交不需要署名

## 边界

- AI 不代替环境安装、工程初始化和 Git 写操作
- AI 给出的代码都经过实际运行验证后才保留；未验证的部分在自查清单里明确标出
- 排错时保留原始报错与操作步骤，不把"执行了命令"当作"验证通过"
