## 一、三分钟演示脚本

准备：后端 `./mvnw spring-boot:run`、前端 `npm run dev` 都已经跑起来，浏览器停在 5173 登录页。

1. **说一句定位**（10 秒）：这是一个经费申请系统，成员申请、老师审批、财务登记实际花费，核心是保证"总预算 = 可用 + 冻结 + 已使用"。
2. **登录成员**（`member1 / 123456`）：指出界面上有"新建申请"表单，卡片显示 1000/0/0。
3. **提交**：点"提交"，数字变 400/600/0，说明"钱从能花变成先留出来"，草稿不占钱。
4. **切换老师**（退出，`teacher1` 登录）：指出成员看不到批准按钮、老师看不到新建表单；批准 500，数字变 500/500/0，说明"只批 500，多留的 100 立刻退回可用"。
5. **切换财务**（`finance1` 登录）：结算 460，数字变 540/0/460，说明"冻结转已使用、没花完的回可用"。

7. **收尾**（10 秒）：后端分层 controller/service/repository/entity，写操作都在事务里，出错会整体回滚（有验证记录）。

## 二、可能被问到的问题

**Q：为什么金额用 BigDecimal？**
A：浮点数有精度误差，0.1+0.2 不等于 0.3；钱用 `DECIMAL(12,2)` 和 `BigDecimal`，并且限制最多两位小数。

**Q：一次操作改两处（项目金额 + 申请状态），失败怎么办？**
A：方法上加了 `@Transactional`，中途抛异常整笔回滚。我做过验证：临时让批准方法在改完金额后抛异常，请求返回 500，但数据库里金额没有被改，仍是 400/600。

**Q：权限怎么做的？会不会只是前端藏按钮？**
A：前端只是按角色显示，真正的拦截在后端。每个写接口按"登录 → 角色 → 归属 → 状态 → 金额"五层校验，越权返回 403，并带原因。

**Q：为什么登录 token 放内存？**
A：演示项目不想引入 Redis 或 JWT 依赖，内存最简单；代价是重启后要重新登录。真实项目会换成 JWT 或持久化会话。

**Q：为什么表结构不用 Hibernate 自动建表？**
A：`ddl-auto=none`，表由 `schema.sql` 建，避免自动建表/删表把演示数据冲掉。

**Q：项目结构怎么分的？**
A：按职责分包：controller 收请求、service 放规则和事务、repository 访问数据库、entity 映射表、dto 放请求体、exception 统一异常。包名 `com.ianchen.backend`。

**Q：哪里用了 AI？**
A：用 AI 解释概念、生成代码草稿、排查报错；环境安装、工程初始化、运行验证、Git 提交和 PR 都是自己做的，提交里有 `AI-Assisted-By` 署名，`.agents/sessions/` 有完整对话记录。

**Q：还有什么没做？**
A：只支持一个项目（没有项目切换）；密码是明文，仅演示；没有分页搜索；token 重启失效。这些在 README 的"尚未完成"里都写了。
