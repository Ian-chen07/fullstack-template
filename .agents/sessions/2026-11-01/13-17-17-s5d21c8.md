别慌，这段 Java 在 C 里就是三十行。我先把等价的 C 写出来，你就知道每个花括号在干什么。

```c
#include <stdio.h>
#include <stdbool.h>

typedef struct {
    int total;
    int available;
    int frozen;
    int used;
} Budget;

bool check(Budget *b) {
    return b->total == b->available + b->frozen + b->used;
}

int main(void) {
    Budget b = {1000, 1000, 0, 0};
    printf("%d/%d/%d\n", b.available, b.frozen, b.used);
    printf("守恒: %d\n", check(&b));
    return 0;
}
```

对应关系：

| Java | C 里对应 |
|---|---|
| `public class Budget { ... }` | `typedef struct { ... } Budget;` 再加属于它的函数 |
| `int total = 1000;` | struct 成员，顺带初始化 |
| `boolean check()` | `bool check(Budget *self)`，`self` 被藏起来了 |
| 方法里直接写 `available` | `self->available` |
| `Budget b = new Budget();` | `Budget *b = malloc(...)` 并把字段初始化 |
| `b.available` | `b->available` |
| `System.out.println(x)` | `printf("%d\n", x)` |
| `public static void main(String[] args)` | `int main(void)` |
| `"守恒: " + b.check()` | 字符串拼接，`+` 会自动把布尔值变成 "true" |

三个可能卡住的点：

1. 花括号嵌套。最外层 `class Budget { }` 是"地盘"，里面只能放字段和方法，不能放普通语句；能放普通语句的只有 `main` 里面。
2. `static`。`main` 是程序入口，启动时还没有任何对象，所以它不能依赖对象，必须是 `static`。C 的 `main` 也没有 self，一个道理。
3. 为什么不是 `if`。其实可以是。`return 表达式;` 和 `if (表达式) return true; else return false;` 完全等价，Java 习惯写前者。

```java
boolean check() {

}
```

| 行 | 代码 | 在干什么 |
|---|---|---|
| 1 | `public class Budget {` | 开始定义一张叫 Budget 的表；`{` 到最后的 `}` 之间都是它的内容 |
| 2 | `int total = 1000;` | 开一栏叫 total，整数，初始填 1000 |

| 6 | `boolean check() {` | 定义一个操作叫 check，交回真假；括号空着表示不需要额外信息 |
| 7 | `// ...` | 注释，不执行 |
| 8 | `return true;` | 把"真"交出去——这是占位，你要改的就是它 |
| 9 | `}` | check 结束 |
| 10 | `public static void main(String[] args) {` | 程序从这里开始跑；这一串是固定格式，先照抄 |
| 11 | `Budget b = new Budget();` | 印一张新表，起名 b，初始 1000/0/0 |

boolean check() {
